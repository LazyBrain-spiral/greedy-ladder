How to use this path

Work through stages in order, and within a stage follow the listed order. Difficulty is LeetCode's label, not a prerequisite order. Read the study target and checkpoint for each stage. Hard extensions may take several sittings.

A solved tick means you completed the problem. Mark a blank-editor retry only after returning 2-3 days later without an editorial. Do not rush the last mixed stage. No fixed question count can guarantee proficiency.

Some problems also appear in Greedy: revisit them with a heap invariant. Some have a better non-heap solution: compare alternatives instead of forcing a priority queue. This path covers the main interview heap patterns, not every possible heap variant.
